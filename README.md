# Proxy_Server

### To run on Linux 

  in terminal:
   Step      Action
   1.        Open terminal in the Proxy_Server folder
   2.        chmod +x scripts/run.sh
   3.        ./scripts/run.sh
  

### To run on Windows 

  in command prompt or powershell:
   Step      Action
   1.        Open terminal in the Proxy_Server folder
   2.        scripts\Run.bat
